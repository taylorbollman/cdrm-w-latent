# Add 150M-family fuzzy-recall calibration and FP32 ordinary attention

Adds native MAD fuzzy-in-context recall and a paired 150M-family CDRM/Transformer experiment. The new models use 12 blocks, D1024 and native V16 symbols: CDRM has 153,175,040 parameters and the MLP-adjusted Transformer 153,437,184. A production `ordinary_attention_precision_policy="fp32"` applies the validated attention placement to every ordinary block in both arms, while retaining BF16 MLPs/head/fabric and the established FP32 state policy. Existing callers default to legacy behavior.

The new preparation, initialization, numerical-validation, profiling and resumable calibration tools preserve native dense training targets and masked development targets. They freeze paired data/order and initialization identities, retain raw numerical evidence, log online to W&B, and support verified artifact retention. Native terminal queries without an earlier mapping remain scored; oracle coverage and the 44.35% answer-prefix shortcut are reported separately. A post-selection diagnostic replays native BF16 metrics exactly and compares the same checkpoint in FP32, retaining subset errors and predictions.

Validation includes 58 data/preparation CPU checks, seven runner checks, 14 reporter checks, 13 diagnostic-evaluation checks, 97 CPU regression passes and four CUDA comparisons with bitwise parity against the archived five-block precision wrapper. Full-width numerical and H100 profiling reports retain their original criteria, failures and qualifications, including first-step Adam sensitivity; see [results](results.md) for the reviewed scope. Earlier failed development attempts remain retained.

All six T256 calibration runs completed ten epochs, and the aggregate passed its source/data/checkpoint/continuation audits. The declared native-accuracy rule selects LR5e-4 for CDRM (99.9009% token accuracy) and LR1e-4 for SEQ (99.8761%). Both approach saturation on this development setting; the four-target difference is not evidence of a robust architecture advantage. At B128, measured T256 updates averaged 0.931s for CDRM and 0.375s for SEQ; the 24-run/25-epoch cost projection is 12.65 training hours when other lengths use the T300 timing proxy, excluding campaign overhead.

Both selected checkpoints replay native BF16 metrics exactly and show zero scored prediction flips when evaluated in FP32. CDRM's 16 native errors comprise five available-lookup errors and 11 unavailable-lookup errors; SEQ's 20 comprise eight and 12. This describes evaluation of the same saved weights, not agreement between FP32 and mixed training trajectories.

This milestone ends with development calibration, numerical/operational evidence and cost estimates. See [results](results.md) and the [storage receipt](storage.json) for reviewed scope and artifact verification. The final four-length, three-replicate comparison and final-test data remain subsequent work; no final accuracy curve is claimed.
